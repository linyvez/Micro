# Автор: Лушпак Вікторія

Базова архітектура мікросервісів, розроблена на Python з використанням FastAPI.

## Архітектура

Архітектура складається з трьох мікросервісів:

- facade-service (Порт 8000) - точка входу, приймає POST/GET платіжні транзакції від клієнтів, надсилає запити до наступних сервісів
- logging-service (Порт 8001) - зберігає всі транзакції які йому надходять та може повертати їх
- counter-service (Порт 8002) - для кожного клієнта підраховує остаточний баланс на його рахунку

## API

Система скаладається з 5 API - 3 основні (передбачені завданням) та 2 допоміжні (для зручного тестування).

- POST / - створення транзакції
- GET /accounts - список всіх балансів
- GET /user/{user_id} - баланс та список транзакцій (історія) певного користувача
- GET /time-taken - (допоміжна) - час обробки на logging та counter services
- DELETE /state - (допоміжна) - очищення всіх даних сервісів, включно з словниками балансів, логів та вимірювання часу обробки

## Prerequisites

- Docker
- Docker Compose

Всі інші залежності перераховані у requirements.txt та автоматично враховані у Dockerfile.

## Build and Launch

```
docker-compose up --build
```

Якщо запуск успішний, можна переглянути документацію за цим посиланням: http://localhost:8000/docs.
